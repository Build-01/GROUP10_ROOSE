# ROOSE Hotel Visual Style

## Color and surfaces

- Use white for the full application background and content surfaces.
- Use fine gold borders and dividers for cards, fields, tables, and page accents.
- Use coffee brown for headings, body text, selected navigation, focus states, and primary actions.
- Keep hover feedback subtle and keep unselected controls white.

## Brand and layout

- Use the supplied ROOSE swan mark as a small brand detail. The swan and halo artwork is inspiration for graceful gold accents, not a full-screen background.
- Keep the login and first-run setup centered and spacious, with aligned fields and one clear primary action.
- First-run setup and returning-staff login share the same layout. Only the title, helper text, fields, and button label change.
- The first run creates the initial authorized staff account. After that, show sign-in; new staff accounts belong in a protected management workflow.
- Use Georgia for the wordmark and page headings; use Segoe UI for labels, buttons, and data tables.
- Avoid heavy panels, competing accent colors, unnecessary decoration, and crowded content.
